# Windows云电脑：不用买整机，按月租一台云端 Windows 做远程桌面、挂机和办公的配置与价格参考

搜 Windows 云电脑的人，需求其实分得很开。有人想要一台 24 小时不断电的 Windows 留在云上，挂游戏、挂软件、跑长时间下载；有人是本机太旧，跑不动某个只有 Windows 版的程序；还有人只是需要一个随时能连进去的干净桌面，用来办公、测试，或者临时顶一顶。

商业云桌面能解决这些需求，Windows 365、AWS WorkSpaces 都是这个路子。它们开通即用、管理省事，但按用户按月计价，权限收得紧，默认不给你完整管理员身份，价格也高一档。另一条路更土，却便宜得多：租一台支持 Windows 镜像的云服务器，用远程桌面连上去。没有成体系的管理控制台，但你有完整管理员权限，能随时重装系统、换机房、加硬盘。

下面按后一种思路展开，以雨云（rainyun）为例，把配置门槛、各区域档位价格、显卡云的计费方式，以及几个下单前容易忽略的限制讲清楚。

## 云电脑和"远程控制自己的电脑"是两回事

这两个概念经常被混着用。远程控制连的是你自己的设备——家里那台主机得开着机、连着网，你才能连上去；机器断电，工具再好也没用。云电脑给的是一台部署在云端的独立主机，7×24 在线，不看你本机有没有开机、性能如何。

所以如果你的痛点是"出差时家里电脑断电了""公司那台老笔记本带不动某个软件"，云电脑对症。如果只是想用手机翻一下自己电脑里的文件，云电脑不解决你的问题，别为它花钱。

目前做 Windows 云电脑的技术路线主要有三条：

1. **商业云桌面**——Windows 365、AWS WorkSpaces、天翼云电脑这类。开通即用，配置选项少，按用户收费，价格明显高一档。
2. **显卡云 / GPU 云电脑**——带独立显卡的云端主机，面向游戏串流、3D 渲染、AI 推理这些场景，按小时或按月计费。
3. **云服务器 + Windows 镜像 + RDP**——最自由也最便宜。你得自己管系统、自己配远程桌面，但一个月几十块就能有一台。

雨云这边，第 2 和第 3 条路线都能买到。

## 云端 Windows 要什么配置才跑得动

先说几个硬门槛，避免买完才发现装不上。

**内存**。官方的系统选择建议里写得很直接：Windows 本身内存占用大，建议选 2G 内存及以上的配置。实际用起来，2G 能开桌面、跑一两个轻量程序，多开几个浏览器标签就开始卡；4G 是比较舒服的起步线，8G 才能不将就。

**硬盘**。雨云各套餐默认 30GB 系统盘（Linux 镜像 20GB 就够用），Windows 装完系统和常用软件大概会吃掉一半以上。不够可以弹性扩容，高速固态 0.4 元/G/月，机械盘 0.1 元/G/月。

**带宽方向**。远程桌面流不流畅，取决于服务器到你这一侧那一段速度。雨云配置页把带宽写成"上行 ×M / 下行 ×M"，美国机型常见的是上行 20M、下行 30M 这样的组合。挂机和办公对带宽要求不高，串流游戏就完全是另一回事了。

**流量型还是不限流量型**。带大带宽标识的通常是流量叠加型，每月用不完的流量可以累积到下个月，用完之后被限速到 5M（部分机型 1M），可以单独买流量包恢复速度；不限流量型带宽会小一些，但不用盯着流量过日子。

## 显卡云：真要显卡的那种云电脑

如果光有 CPU 不够用，雨云的显卡云是另一条产品线。

广东深圳的机型目前是 AMD EPYC 7A23 搭配 NVIDIA Tesla V100（16G 显存），16 核 CPU、24GB 内存，NVMe 盘 100–2000GB 可调，上行 50M、下行 200M，不限流量，带深圳电信 20G+ 月防，支持 CUDA。它有两种计费方式：

- **日常网吧型**：固定 28 元/月起，每月赠送 5 小时开机时长，超出部分 2.5 元/小时，关机不计时。适合偶尔用一次的场景。
- **算力长租型**：638 元/月起，不限开机时长，适合需要长期在线的用途。

广州也有机型在售，此前公开的配置是 AMD EPYC 7543 + RTX 3080（10G 显存）、12 核 24G、200Mbps 不限流量，固定月付 978 元，另有一个 29 元/月加 2.5 元/小时的网吧型档位。显卡机型换代比较频繁，深圳那台就是从 RTX 3080 换到 V100 的，下单前看一眼当前标配。

一台带独显的云电脑，是唯一能让远程桌面跑起 3D 应用和云游戏的选项。如果你的需求只是文档、代码、后台软件，显卡这部分钱可以省下来。👉 对比雨云显卡云各档位当前报价 更清楚。

## 从注册到连上桌面

流程不复杂，大概是这样：

1. 通过优惠链接进官网注册账号，绑定微信（这一步会触发新用户券的发放）。
2. 进控制台，选"计算 → 云服务器"，挑机房、CPU 机型、CPU/内存档位、硬盘容量。
3. 选公网 IP 模式：NAT 还是独立 IP；选镜像，系统里挑 Windows 版本，也可以挑预装好环境的模板。
4. 付费，等一分钟左右机器起来。
5. 控制台里用 Xtermjs 或 NoVNC 模式直接连（NoVNC 在系统还没配好网络时特别有用），系统就绪后再用本地远程桌面客户端连。
6. 想开放端口、改防火墙规则，都在控制台里操作。

Windows 镜像第一次开机做完初始化要等几分钟，别以为卡死了。

## 省钱的部分：券、折扣和积分

雨云的价格本身不高，但叠加上去能再省一截。几条已确认的规则：

- **首月 5 折券**。通过推广链接注册并绑定微信后，系统自动发一张无使用门槛的 5 折券，不用手动输码。这是新用户能拿到的最大的单笔折扣，适合拿它试一个月看看延迟和稳定性。
- **长周期折扣**。季付 9 折、半年付 8 折、年付 7 折，可以和券叠加使用。
- **积分返利**。购买和续费能拿到消费金额 10%–20% 的积分，2000 积分折合 1 元，可以直接提现或换优惠券。每日签到固定给 500 积分，绑定微信、邮箱、关注官方账号也有一次性积分。
- **试用与退款**。云服务器和游戏云支持 1 元试用 1 天（每款限一次，贵的机型试用价会高一些）；7 天无理由退款，每个账号限 3 次。

先把首月 5 折券用掉试一台，觉得延迟和稳定性可以，再按年付 7 折续下去，是成本最低的路径。👉 领券后按这个顺序下单更划算。

## 几个下单前该知道的限制

**NAT 模式只能映射 10 个端口**。雨云默认给的是共享 IP 的 NAT 网络，开放 10 个端口（游戏云是 15 个）。远程桌面要用 3389，在 NAT 下得走端口映射连接；如果你需要默认端口或全部端口，得加购独立 IP——普通地区 5 元/月，江苏宿迁 150 元/月（对应独享 150G 防御），湖北十堰 50 元/月且是必买项。

**流量用完之后会限速**。流量叠加型机型超出套餐后会被压到 5M 甚至 1M，需要买流量包才能恢复。挂机类用途不容易超，下载和串流就要算一算。

**国外节点的延迟和稳定性差异明显**。国内三网访问最舒服的是宿迁、温州、重庆这类国内节点；香港带宽小，晚高峰偶有波动；美国、德国延迟本身就高，适合对延迟不敏感的用途。想在国内节点用 80/443 端口跑网站，域名要备案。

**年付折扣有例外**。社区整理的资料里提到湖北十堰节点的长周期折扣政策与其他区域不一致，下单时看结算页实际金额最稳妥。

## 到底该买哪一台

把钱花在刀刃上，大概是这样分的：

- **只是想有个能连进去的 Windows 桌面**：重庆 1 核 1G（￥18/月）能跑起来但不舒服，加到 2 核 2G（￥25/月）体验差别很大，这 7 块钱值得花。
- **要长期挂机、要求国内低延迟**：江苏宿迁走 NAT，或者温州的高防大带宽机型。宿迁便宜但独立 IP 贵，温州反过来，按自己用不用 80/443 端口来选。
- **要显卡**：深圳显卡云。一个月用几次就选日常网吧型，28 元月租加 2.5 元一小时；每天都开就直接算长租型的 638 元是否划算。
- **只是写代码、跑服务**：Linux 镜像更省内存也更省硬盘，没必要为了 Windows 多付一档配置的钱。

最后提醒一句：云服务器跑 Windows 的核心成本不在软件，在内存。任何一家服务商都一样，2G 是底线，4G 是舒服线。把这一条记住，配置单基本不会选错。
